# Changelog

## 2.0.0 — Architecture redesign

- Defines a shared Unified World State.
- Separates simulation scheduling from rendering.
- Specifies hybrid raster/screen-space/software-ray rendering.
- Adds temporal history validation requirements.
- Defines multi-scale fluid simulation direction.
- Establishes browser capability detection and graceful fallback.

This release is an architecture specification, not a complete rendering engine.
